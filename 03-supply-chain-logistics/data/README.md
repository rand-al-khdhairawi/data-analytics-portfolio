# Data for Project 3

Not included in the repository. Download **DataCo Smart Supply Chain for Big Data Analysis** (Mendeley Data, also on Kaggle) and save `DataCoSupplyChainDataset.csv` here. You do not need the other two files in the download.

The file contains customer names, emails and street addresses. The pipeline drops these columns when building the database, and the repository must never contain the raw file.

Check the dataset page for its license before reusing the data.
