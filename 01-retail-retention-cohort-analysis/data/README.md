# Data for Project 1

Not included in the repository. Download **Online Retail II** (UCI Machine Learning Repository, also copied on Kaggle) and save it here as `online_retail_II.csv`.

The UCI download is an Excel file. If you have the `.xlsx`, open it in Excel, combine both sheets into one table if needed, and use File > Save As > CSV. The first row must keep the original headers (`Invoice`, `StockCode`, `Description`, `Quantity`, `InvoiceDate`, `Price`, `Customer ID`, `Country`).

Check the dataset page for its license before reusing the data.
